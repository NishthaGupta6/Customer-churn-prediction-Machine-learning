# Customer-churn-prediction-Machine-learning
This project develops a machine learning based solution to predict customer churn by identifying customers who are likely to discontinue a service.                  
The workflow includes data preprocessing, exploratory data analysis and feature engineering to uncover patterns influencing churn behaviour.
Classification models such as Logistic regression and Random Forest were implemented and evaluated using performance metrics to compare their predictive capabilities.
The project demonstrates the application of machine learning techniques to support data-driven customer retention strategies.

## Problem statement
Can we accurately predict which customers are at risk of churning based on their demographic, behavioral and engagement characterstics? Early identification of such customers can help the business reduce revenue loss and improve customer retention strategies

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.

## Key findings
Confusion matrix:
 True negatives: 940, 
 False positives: 1, 
 False Negatives: 36, 
 True Positives: 149

Performance metrics results:
Accuracy ~ 96.7% , 
Precision ~ 99.3% , 
Recall ~ 80.5% , 
F1 score ~ 88.9% 

## Business impact
The model successfully identifies customers at risk of churning with high precision, enabling businesses to take targeted retention actions. Such insights can help improve customer loyalty, reduce churn-related revenue loss, and support informed business decision-making.
